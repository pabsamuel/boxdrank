# Updates Inbox (working name)

A monday.com marketplace app idea: one searchable, filterable list of the
updates across every item, board and workspace the user can see.

**Status, 2 Oct 2026: Gate 0 started; no app code. 0 / 6 = 0%** (`PROGRESS.md`).
- **Next:** `GATE0.md`. Samet runs check 1 (the API playground). Research
  covers checks 2–4.

## Why this one

Patrick Fallon (BotSquad) wrote on 26 Sep 2026, unprompted (`SPEC.md`):

> "to me the biggest pain point around monday updates is that they're siloed
> within individual items … If there was a way to have an inbox showing all
> updates that was filterable and easily searchable, I think that's something
> people would genuinely pay for."

The same person's other suggestion became Automation Inventory, which is
built and submitted. INFERENCE: much of Inventory's code carries over:
- the cross-board list, search and filters;
- the Object and board view, themes and the welcome page;
- the Sidekick tool, the server and the security answers.
