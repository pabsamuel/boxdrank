# Unanswered Updates (working name)

A monday.com marketplace app idea: one list, across every board the user can
see, of item updates that nobody has answered for N days.

**Status, 8 Oct 2026: Gate 0 started; no app code** (`GATE0.md`).

Origin: the Updates Inbox Gate 0 (2 Oct) found that monday covers "all
updates" and "mentions of me I didn't answer", but nothing documented covers
"threads nobody answered, across boards" (`../monday-updates-inbox/COMPETITORS.md`).

Rules: `CLAUDE.md`. The gate's rules were written before any result.
