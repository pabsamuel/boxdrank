# PROMPT: Hook doctor

The hook decides whether a post reaches 400 people or 40,000. It is worth more attention than
the rest of the post combined. Run this on every batch.

---

Here are this week's hooks:

```
1.
2.
3.
4.
5.
```

For each one, do this in order:

**Step 1 — Diagnose.** Score it 1–10 on each, one line of reasoning total, no padding:
- **Specificity**: does it name a person or a moment in the first 3 words?
- **Tension**: is there something unresolved that forces the next line to be read?
- **Self-recognition**: would a 31-year-old Saudi banker think "that's me" instantly?
- **Non-genericness**: could this exact hook appear on 500 other English-teaching accounts?
  (If yes, score 1 regardless of how polished it is.)

**Step 2 — Rewrite.** Give 5 alternatives per hook, ordered from safe to risky. The last one
should make me slightly uncomfortable. No explanations.

**Step 3 — Kill.** Tell me which of the 5 original hooks you would delete entirely rather than
fix, and what post idea should replace it.

Rules:
- Max 8 words per hook.
- No questions that can be answered "no" ("Do you want to improve your English?" — dead).
- No numbers-first hooks ("5 phrases...") unless the number is genuinely surprising.
- Arabic hooks are allowed and often stronger. Mark which language each is in.
