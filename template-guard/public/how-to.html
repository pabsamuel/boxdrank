How to use Template Guard

Template Guard finds what a board lost when it was copied from its template: missing columns, groups and views, and connect columns still pointing at the template's board. It is read-only and never changes a board.

49-second demo. Direct link: demo.mp4

1. Install

Install Template Guard from the monday apps marketplace. It asks only for read permissions (boards:read, account:read, me:read).

2. Mark your template

Open the board you duplicate for every client or project. Click + next to the board's views → Apps → Template Guard. In the view, click Use this board as a template. Template Guard saves the board's configuration (never its items).

3. Compare a copy

Open any board copied from the template, add the Template Guard view the same way, choose the template under Compare against and click Compare. Every difference is listed, most serious first: miswired, missing, altered, and (if you switch them on) cosmetic.

4. Fix what matters

Each finding says what changed, why it matters and how to fix it. The checklist links straight to the board. Connect columns are always fixed by hand, because only you know which board a copy should point at.

5. Ask sidekick

Ask monday's AI assistant: "What did the Client A board lose from its template?" Template Guard's Sidekick tool answers with the differences. The same check is available as the automation action Compare [Board name] with its template.

6. Stay covered (Pro)

Pro re-checks every compared copy every six hours and alerts you when one drifts.
