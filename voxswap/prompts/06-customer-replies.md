# Write a reply to a customer

Use for any customer message you do not want to write from scratch.

---

Help me reply to a customer.

The situation:

```
<WHAT IS HAPPENING — e.g. "order is done", "I need to say no",
 "their samples are too quiet", "they're asking why it's taking so long">
```

Their message, if there is one:

```
<PASTE IT>
```

Order ID, if relevant: `<ORDER ID>`

Write the reply. Rules:

* Plain language. No jargon — they do not know what LUFS or a slot is.
* Short. Lead with the answer, not the background.
* Honest about anything imperfect, **before** they find it themselves. If the QC
  report shows a flagged line, mention it.
* If I am saying no, the reason is one sentence and there is no apology
  paragraph. "Every voice needs its owner's own signed consent and a short
  verification recording — I can't start without that" is a complete answer.
* If I need something from them, put it in a short numbered list at the end.

Check `templates/delivery-email.md` and `templates/customer-intake-form.md`
first — if one of those already covers it, adapt it rather than writing new.

If the order is finished, read its `qc.md` first so the numbers in the email are
real.
