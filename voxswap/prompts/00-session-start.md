# Session start

Paste this at the beginning of every Claude Code session in `voxswap/`.

---

Read `STATUS.md`, then `CLAUDE.md`, then skim `ROADMAP.md`.

Tell me, briefly:

1. Where this project actually stands right now.
2. What "Next exact action" says, and whether it still makes sense.
3. Anything in `STATUS.md` marked unverified or a known gap that I should be
   worried about before doing anything else.

Then stop and wait. Do not start changing things — I will tell you what I want
to do next.

If I describe a task that one of the prompts in `prompts/` already covers, say
which one, so I learn the shortcut for next time.
